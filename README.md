# Parkour Adventure Camp 🌲🏃‍♂️

> **"Supere obstáculos. Descubra seus limites."**

Website oficial conceitual da agência fictícia de turismo de aventura **Parkour Adventure Camp (PAC)**, situada em **Socorro — SP (Circuito das Águas Paulista / Serra da Mantiqueira)**.

Desenvolvido como projeto acadêmico de ecoturismo e turismo de aventura, combinando estética premium com arquitetura front-end 100% estática.

---

## 🌟 Destaques do Projeto

- **Zero Dependências de Backend:** Funciona de forma 100% estática (HTML5, CSS3 e JavaScript puro).
- **Direção de Arte Premium:** Identidade visual inspirada em marcas de esportes radicais e eco-resorts de luxo.
- **Microinterações 3D:** Cards com profundidade e perspectiva (`perspective`, `rotateX`, `rotateY`, `translateZ`) responsivos à posição do mouse.
- **Hero com Parallax Multicamadas:** Sensação de profundidade com camadas de atmosfera, imagem e tipografia.
- **Timeline Interativa (7 Dias):** Cronograma dinâmico de Segunda a Domingo com *scroll-snap*.
- **Transparência de Custos:** Planilha acadêmica com custo estimado (R$ 2.650) e margem bruta (R$ 540) para o pacote de R$ 3.190.
- **Protocolo de Segurança:** Diretrizes baseadas nos princípios da norma ABNT NBR ISO 21101.
- **100% Responsivo & Acessível:** Adaptado para smartphones, tablets e desktops com respeito a `prefers-reduced-motion`.

## 🚀 Como Executar

Não é necessária nenhuma instalação ou servidor Node/Python.

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/parkour-adventure-camp.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Se desejar hospedar gratuitamente, você pode ativar o **GitHub Pages** nas configurações do repositório (Settings > Pages > Branch: `main` / `root`).
